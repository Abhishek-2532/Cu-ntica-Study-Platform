Chapter 1

Supervised Learning

1.1 Introduction

Supervised Learning is the most widely deployed paradigm of Machine Learning where algorithms learn from a labeled dataset consisting of input features $X$ and correct target outputs $Y$.

ℹ️
Labeled Dataset Structure A labeled dataset contains paired examples $(X_i, Y_i)$ where $X_i$ represents the vector of input observations (e.g. Hours Studied) and $Y_i$ is the ground-truth target label (e.g. Exam Marks).

Working Process Pipeline

1
📉 Ingest Training DataFeed paired features $X$ and true targets $Y$.
2
⚙️ Learn Mapping FunctionAlgorithm computes mapping function $Y = f(X)$.
3
🤖 Generate ModelSave optimized parameters and decision boundary.
4
🚀 Predict New DataModel predicts $Y_{new}$ for unseen input $X_{new}$.

1.2 Characteristics, Applications & Trade-Offs

✅
Easy Evaluation

Held-out ground truth targets allow exact accuracy measurement.

🎯
High Precision

Achieves state-of-the-art predictive performance when well-tuned.

⚠️
Label Bottleneck

Creating manual labels is time-consuming and expensive.

🧠
Overfitting Risk

Models may memorize training noise if hyper-parameters are unconstrained.

Primary Applications

  • Spam & Phishing Email Filtering
  • Medical Disease & Tumor Classification
  • Stock Market Price Trend Prediction
  • Facial Recognition & Speech Identification
  • Credit Risk Scoring & Loan Approval Systems
Chapter 2

Unsupervised Learning

2.1 Overview & Key Concepts

In Unsupervised Learning, datasets contain input features $X$ only, without any target labels $Y$. The model must autonomously explore and extract underlying patterns, clusters, and latent relationships.

1
📉 Unlabeled Input DataFeed raw features $X$ without target answers.
2
🧠 Discover Similarity MetricsCalculate Euclidean/Cosine distances between data vectors.
3
👥 Form Clusters & PatternsGroup data points into distinct clusters or reduced dimensions.

2.2 Three Major Unsupervised Tasks

👥
1. Clustering

Grouping similar observations together (K-Means, DBSCAN, Agglomerative).

e.g. Customer Market Segmentation
🛒
2. Association Rule Mining

Discovering item co-occurrence relationships (Apriori Algorithm).

e.g. Market Basket Analysis (Bread → Butter)
📉
3. Dimensionality Reduction

Compressing 100+ feature spaces into low dimensions (PCA, t-SNE, UMAP).

e.g. Feature Compression & Visualization

Chapter 3

Reinforcement Learning (RL)

3.1 Trial-and-Error Learning Mechanics

In Reinforcement Learning (RL), an autonomous Agent interacts with a dynamic Environment. The agent selects Actions to maximize cumulative numerical Rewards over time.

🤖
Agent

The active learner/decision-maker (e.g., Self-driving vehicle software).

🌍
Environment

The external world in which the agent operates (e.g., Roadway & Traffic).

📍
State ($S_t$)

Current snapshot observation of the environment (e.g., Red Traffic Light ahead).

⚙️
Action ($A_t$)

Set of possible moves available to the agent (Steer Left, Accelerate, Brake).

🎉
Reward ($R_t$)

Feedback signal (+1 for reaching goal safely, -100 for collision).

Applications of Reinforcement Learning

  • Autonomous Vehicles & Self-Driving Navigation
  • Industrial Robotics & Warehouse Manipulators
  • Game Intelligence (AlphaGo, Chess, StarCraft II)
  • LLM Alignment via Reinforcement Learning from Human Feedback (RLHF)
Chapter 4

Regression Algorithms

4.1 Continuous Numerical Target Modeling

Regression models predict continuous numerical quantities ($Y \in \mathbb{R}$) based on input feature vectors $X$.

Types of Regression

  • Simple Linear Regression: Fits a straight line $Y = eta_0 + eta_1 X + \epsilon$.
  • Multiple Linear Regression: Models multiple predictor inputs $Y = eta_0 + eta_1 X_1 + eta_2 X_2 + ... + eta_n X_n$.
  • Polynomial Regression: Fits non-linear curves $Y = eta_0 + eta_1 X + eta_2 X^2 + ...$.

Evaluation Metrics for Regression

Regression Performance Metrics
MetricFull NameFormula / Description
MAEMean Absolute ErrorAverage absolute deviation $ rac{1}{n}\sum |y_i - \hat{y}_i|$. Easy to interpret.
MSEMean Squared ErrorAverage squared difference $ rac{1}{n}\sum (y_i - \hat{y}_i)^2$. Penalizes large errors.
RMSERoot Mean Squared Error$\sqrt{ ext{MSE}}$. Expressed in the exact same units as target $Y$.
$R^2$ ScoreCoefficient of DeterminationProportion of target variance explained by model ($0.0 o 1.0$).
Chapter 5

Classification Algorithms

5.1 Categorical Target Modeling

Classification algorithms assign observations into discrete class categories (e.g., $Y \in \{0, 1\}$ or $Y \in \{ ext{Cat}, ext{Dog}, ext{Bird}\}$).

⚖
Binary Classification

Two mutually exclusive classes (Spam vs Not Spam, Tumor vs Healthy).

🎯
Multi-Class Classification

Single target selected from three or more classes (Apple vs Banana vs Orange).

🏷
Multi-Label Classification

Multiple non-exclusive tags assigned simultaneously (e.g. Image contains Dog + Tree + Car).

Classification Evaluation Metrics & Confusion Matrix

  • Accuracy: Ratio of total correct predictions $ rac{TP + TN}{TP + TN + FP + FN}$.
  • Precision: Exactness of positive predictions $ rac{TP}{TP + FP}$.
  • Recall (Sensitivity): Ability to find all true positive instances $ rac{TP}{TP + FN}$.
  • F1-Score: Harmonic mean of Precision and Recall $2 \cdot rac{ ext{Precision} \cdot ext{Recall}}{ ext{Precision} + ext{Recall}}$.
  • ROC-AUC: Area under Receiver Operating Characteristic curve measuring trade-off between True Positive and False Positive rates.
Chapter 6

Decision Tree Algorithms

6.1 Structure & Splitting Mechanics

A Decision Tree partitions data into hierarchical IF-ELSE decisions starting from a Root Node, passing internal decision nodes, and arriving at final Leaf Nodes.

[Root Node] Age < 30?
│
├── Yes → [Internal Node] Student Status?
│      ├── Yes → [Leaf Node] Output: Buy Computer
│      └── No → [Leaf Node] Output: No Purchase
│
└── No → [Internal Node] Income Level?
      ├── High → [Leaf Node] Output: Buy Computer
      └── Low → [Leaf Node] Output: No Purchase

Splitting Criteria Formulas

  • Gini Impurity: $ ext{Gini} = 1 - \sum_{i=1}^{C} p_i^2$ (Measures node impurity; lower is better).
  • Entropy: $H(S) = -\sum_{i=1}^{C} p_i \log_2(p_i)$ (Measures randomness in information).
  • Information Gain: $ ext{Gain}(S, A) = H(S) - \sum rac{|S_v|}{|S|} H(S_v)$ (Higher gain determines optimal split).
Chapter 7

Random Forest (Ensemble Learning)

7.1 Bagging & Wisdom of the Crowd

Random Forest is a powerful Ensemble Machine Learning algorithm that constructs a large collection of de-correlated Decision Trees using Bootstrap Aggregating (Bagging) and random feature subsets.

1
🎲 Bootstrap SamplingCreate $N$ random samples with replacement from training dataset.
2
🌳 Train Multiple TreesBuild independent decision trees using random sub-features for each split.
3
🗸 Aggregate PredictionsClassification: Majority Vote; Regression: Average Prediction.
🌟
Why Random Forests Excel By averaging predictions across hundreds of individual decision trees, Random Forests dramatically reduce variance and overfitting without increasing bias.
Chapter 8

Support Vector Machines (SVM)

8.1 Maximum Margin Hyperplanes & Kernel Trick

Support Vector Machine (SVM) finds the optimal decision boundary (Hyperplane) that maximizes the Margin between classes in high-dimensional vector space.

⚖
Hyperplane

Decision boundary separating class vectors ($W^T X + b = 0$).

📏
Margin

Perpendicular distance between boundary and closest data points. Maximum margin maximizes generalization.

🟢
Support Vectors

The critical boundary data points that uniquely determine the hyperplane's orientation.

⚡
Kernel Trick

Maps non-linearly separable inputs into higher-dimensional Hilbert space (Linear, Polynomial, RBF, Sigmoid).

Chapter 9

Artificial Neural Networks (ANN)

9.1 Biological Motivation & Mathematical Neuron

Artificial Neural Networks mimic biological brain structures using interconnected layers of artificial neurons (perceptrons).

📝
Mathematical Neuron Equation $z = f\left(\sum_{i=1}^n w_i x_i + b ight)$ where $w_i$ are learned weights, $b$ is bias, and $f$ is a non-linear activation function.

Common Activation Functions

  • Sigmoid: $f(z) = rac{1}{1 + e^{-z}}$ (Scales output between 0 and 1; ideal for binary output).
  • ReLU (Rectified Linear Unit): $f(z) = \max(0, z)$ (Most popular; prevents vanishing gradients).
  • Tanh: $f(z) = anh(z)$ (Scales output between -1 and +1).
  • Softmax: Converts final vector into probability distribution summing to 1.0 for multi-class targets.
Chapter 10

Deep Learning Architectures

10.1 Why "Deep"? Automated Feature Hierarchy

Deep Learning utilizes deep neural networks containing multiple hidden layers (often tens or hundreds) to learn increasingly complex hierarchical feature representations directly from raw data.

📷
1. Convolutional Neural Networks (CNN)

Uses spatial convolution filters for Computer Vision, Image Classification, and Object Detection.

🔄
2. Recurrent Neural Networks (RNN & LSTM)

Uses recurrent loops and memory cells for Sequential Time-Series and Natural Language Processing.

⚡
3. Transformer Architecture

Uses Multi-Head Self-Attention mechanisms powering Large Language Models (LLMs) like GPT-4, Gemini, and Claude.

Python Code Hands-On: Classical Machine Learning Model Comparison

Python 3.10 (scikit-learn) 
# Classical Machine Learning Model Comparison Script
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.svm import SVC
from sklearn.metrics import accuracy_score

# Load Benchmark Dataset
iris = load_iris()
X, y = iris.data, iris.target

# Train-Test Split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Initialize Classical Models
models = {
    "Decision Tree": DecisionTreeClassifier(),
    "Random Forest": RandomForestClassifier(n_estimators=50),
    "Support Vector Machine": SVC(kernel='rbf')
}

# Train & Evaluate Models
for name, model in models.items():
    model.fit(X_train, y_train)
    preds = model.predict(X_test)
    acc = accuracy_score(y_test, preds)
    print(f"{name} Test Accuracy: {acc * 100:.2f}%")
