Chapter 1: Supervised Learning

Introduction

Supervised Learning is the most widely used type of Machine Learning where the model learns from labeled data .

A labeled dataset contains:

  • Input Features (X)
  • Correct Output Labels (Y)

The algorithm learns the relationship between X and Y so that it can predict outputs for unseen data.

Example

The algorithm learns:

Later,

5 Hours

Prediction:
63 Marks

Chapter 10: Deep Learning

Introduction

Deep Learning is a subset of Machine Learning that uses deep neural networks with multiple hidden layers to automatically learn complex patterns from large amounts of data.

Traditional ML often requires manual feature engineering, whereas Deep Learning learns features automatically. 

Input Data
     │
     ▼

     │
     ▼

     │
     ▼
Hidden Layer 3
     │
     ▼
Output

Why "Deep"?

A neural network with many hidden layers (typically more than 3) is called deep . More layers allow the model to learn increasingly abstract features:

  1. Layer 1: Edges
  2. Layer 2: Shapes
  3. Layer 3: Objects
  4. Layer 4+: High-level concepts (e.g., faces, cars)

Popular Deep Learning Architectures

1. Artificial Neural Networks (ANN)

Used for structured/tabular data.

2. Convolutional Neural Networks (CNN)

Designed for image and video processing.

Applications:

  • Face recognition
  • Medical image analysis
  • Object detection

3. Recurrent Neural Networks (RNN)

Designed for sequential data.

Applications:

  • Speech recognition
  • Language modeling
  • Time-series forecasting

4. Long Short-Term Memory (LSTM)

A type of RNN that can learn long-term dependencies.

Applications:

  • Machine translation
  • Stock prediction
  • Text generation

5. Transformers

Modern architecture using attention mechanisms.

Applications:

  • ChatGPT
  • BERT
  • GPT
  • Machine translation
  • Document summarization
