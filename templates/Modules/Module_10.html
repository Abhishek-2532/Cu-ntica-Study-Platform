Chapter 5

Classical Preprocessing for Quantum Encoding

5.1 Dimensionality Reduction & Normalization

Because NISQ hardware has a limited number of physical qubits ($N \le 10$ for clean simulation), classical preprocessing is mandatory. Input feature vectors must be normalized to $[0, \pi]$ for Angle Embedding or unit norm $\|x\| = 1$ for Amplitude Embedding.

Chapter 6

Quantum Data Encoding Implementation

6.1 Hands-On Code: Data Encoding Pipeline in PennyLane & Qiskit

Python 3.10 (PennyLane) 
import pennylane as qml
from pennylane import numpy as np
from sklearn.datasets import load_iris
from sklearn.preprocessing import MinMaxScaler
from sklearn.decomposition import PCA

# 1. Load & Preprocess Iris Dataset
data = load_iris()
X, y = data.data, data.target
X_binary = X[y != 2] # Filter for binary classification (0 vs 1)
y_binary = y[y != 2] * 2 - 1 # Convert labels to {-1, +1}

# 2. PCA Reduction to 2 features for 2-qubit circuit
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_binary)

# 3. MinMax Scaling to [0, pi] for Angle Embedding
scaler = MinMaxScaler(feature_range=(0, np.pi))
X_scaled = scaler.fit_transform(X_pca)

print("Preprocessed Sample Features (Angles):", X_scaled[0])

Chapter 8

Variational Quantum Circuit Design

8.1 Entangling Ansätze Selection

Choosing the right circuit ansatz balances expressivity and trainability. Common choices include Strongly Entangling Layers, RealAmplitudes, and Hardware-Efficient Ansätze (CZ/CNOT entanglers with single-qubit $R_y( heta)$ and $R_z(\phi)$ rotation gates).

Chapter 9

Model Training & Parameter Optimization

9.1 Optimization Algorithms

Training variational parameters $ heta$ involves evaluating cost function loss gradients. Optimizers include Gradient-Based Adam / Nesterov (via Parameter Shifts) and Gradient-Free COBYLA / SPSA (ideal for noisy physical hardware).

Chapter 10

Mitigating Barren Plateaus & Optimization Traps

10.1 Gradient Vanishing Solutions

Avoid Barren Plateaus by initializing variational weights near zero ($ heta pprox 0$), employing shallow circuit depths ($L \le 3$), and using local cost functions (measuring individual qubit Pauli-Z operators instead of global operators).
